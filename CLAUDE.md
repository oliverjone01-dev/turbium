# TURBIUM - Operating System (v1.1)

Независимое AI-агентство для МСБ России. «Элемент вашего роста». НЕ имеет отношения к GENGROUP, но использует его агентов как инструменты.

## Куда смотреть
- `knowledge/INDEX.md` - карта репозитория. Начинать поиск отсюда
- `knowledge/decisions.md` - принятые решения. Не пересматривать без новой записи
- `knowledge/facts.md` - проверенные цифры с источниками
- `sessions/files/INDEX.md` - файлы, присланные в прошлых чатах. Брать отсюда, повторно у пользователя не просить. Новый файл из чата сразу сохранять скриптом `.claude/skills/pereezd/scripts/save-file.sh`. Репозиторий публичный: ПДн, цены, договоры в git не класть, только `--link` на приватное хранилище (правила в скилле pereezd)
- `sessions/handoff/` - если сессия стартовала как продолжение, прочитать указанный файл первым

## Жёсткие правила
1. Каждая публичная цифра: источник или тег [ГИПОТЕЗА]. Без источника - блок. Разметку делает data.
2. Вымышленные кейсы запрещены. До реальных: «модельный расчёт» с пометкой.
3. Запретный словарь: «уникальный», «эксклюзивный», «не упусти», «только сегодня», «заработай миллион».
4. Em dash запрещён (дефис или перестроить фразу).
5. Критический артефакт (публикация, продукт, бюджет >200К) проходит агента feniks до деливера.
6. Персональные данные клиентов: только российские AI (152-ФЗ).

## Экономия контекста
- Сессия живёт до ~150-200K контекста, дальше скилл `pereezd` (датчик сам подскажет).
- Широкий поиск по файлам отдавать субагенту Explore, в основной контекст брать выводы.
- Большие данные (xlsx, json, выгрузки) не читать целиком: считать скриптом, смотреть итог.
- Файлы и страницы генерировать скриптами, а не печатать моделью.
- Чек-ины по правилам из `pereezd`: 50 мин, дальше 4 часа, ночью нет, 3 пустых - стоп.
