# pereezd - переезд в новую сессию

Плагин для Claude Code и Cowork. Когда контекст сессии разрастается (150-200K токенов),
Claude сам сохраняет работу, пишет передаточный файл и открывает новую сессию с первой
задачей. Длинная сессия дорогая: каждый ход перечитывает весь контекст. Переезд режет
расход квоты без потери качества.

Внутри:
- скилл `pereezd` - порядок переезда и правила чек-инов;
- команда `/pereezd` - переехать вручную;
- датчик `hooks/context-meter.py` - перед каждым сообщением меряет контекст и подсказывает
  Claude, что пора. Пороги: 150K мягкий, 200K жёсткий, пауза 60 минут = кэш остыл.
  Меняются переменными `PEREEZD_SOFT`, `PEREEZD_HARD`, `PEREEZD_IDLE_MIN`, `PEREEZD_IDLE_CTX`.

Отключить на один ход: написать в сообщении «без переезда».

## Установка

### Вариант 1. Архив в claude.ai (Cowork и Claude Code одним движением)
1. Взять `dist/pereezd-plugin.zip` (собирается `./build.sh`).
2. claude.ai -> Настроить (Customize) -> Плагины -> Добавить -> Загрузить плагин.
3. Плагин появится в Cowork и Claude Code этого аккаунта. Скилл и команда работают везде,
   датчик-хук - в Cowork и Claude Code (в обычном чате хуки не запускаются).

### Вариант 2. Claude Code из каталога (CLI, десктоп)
Нужен доступ на чтение к репозиторию `oliverjone01-dev/turbium` (git-учётка на машине).
```
/plugin marketplace add oliverjone01-dev/turbium
/plugin install pereezd@turbium
```
Обновление: `/plugin marketplace update turbium`.

### Вариант 3. Только скилл
`dist/pereezd-skill.zip` - папка со SKILL.md и шаблоном. Для загрузки в раздел навыков
claude.ai или распаковки в `~/.claude/skills/`. Датчика нет, переезд по команде и по
самооценке Claude.

## Требования
- `python3` в PATH для датчика. Нет Python (часто на Windows) - датчик молча не работает,
  скилл и `/pereezd` остаются.
- Новую сессию сам скилл открывает, только если есть инструмент `create_session`
  (облачный Claude Code, облачный Cowork). Иначе выдаёт готовый стартовый промпт для
  вставки в новый чат.

## Где хранится передача
`sessions/handoff/<дата>-<проект>-<задача>-v<N>.md` в проекте. Шаблон кладётся туда
при первом переезде из `skills/pereezd/templates/handoff.md`.

## Важно
Не ставить в проекты, где датчик уже подключён через `.claude/settings.json`
(turbium, t1): подсказка придёт дважды.
