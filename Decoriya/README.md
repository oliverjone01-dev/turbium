# Decoriya

Кликабельная демонстрация для партнёров: лендинг → витрина в стилистике Авито → десять страниц объявлений → просмотр галереи → подготовка обращения.

## Просмотр

Из корня репозитория:

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080/Decoriya/`.

Опубликованная версия: https://oliverjone01-dev.github.io/turbium/Decoriya/

## Состав

- Четыре основных предложения из согласованной презентации, 20 карточек.
- Три тематических предложения для тестирования: русский стиль, ледяное серебро, пастель; 15 новых слайдов.
- Подборка «Новая подача»: три дополнительные версии объявлений о входах заведений, домах и витринах; 18 карточек с инфографикой поверх фото.
- Девять фотографических сцен новой серии; промпты в `docs/new-photo-prompts.json`.
- Шесть изображений первой серии: три общих вида и три технические иллюстрации.
- Поиск, категории, фильтр избранного, сортировка, отдельные URL, галерея, полноэкранный просмотр и клавиатурная навигация.
- Демонстрационное обращение: локальный черновик, валидация, копирование, без отправки данных.

Это самостоятельный демонстрационный сайт. Он не принадлежит Авито и не публикует объявления на площадке. Цены, отзывы, рейтинги, сроки ответа и выполненные заказы не выдуманы. Тематические изображения показывают варианты оформления; они не представлены как выполненные клиентские проекты.

Цену, комплектацию и доступность дат подтверждает Олеся. Четыре основных предложения и три теста разделены в витрине. Новые стили не объявлены доказанными источниками заказов. Отдельный фильтр `#showroom?phase=creative` открывает три новые версии.

Разбор двух предоставленных пользователем объявлений JOYLED: `docs/creative-reference-review.md`. Заявления конкурента не перенесены в наши условия без подтверждения.

## Файлы

- `data.js` - тексты и состав объявлений.
- `app.js` - маршрутизация и взаимодействия, без внешних зависимостей.
- `styles.css` - адаптивная дизайн-система.
- `assets/slides/` - 53 карточки: семь галерей по пять и три новые по шесть.
- `assets/photos/` - фотографии-концепции и технические иллюстрации.
- `tools/build-slides.py` - воспроизводимая сборка новых SVG-слайдов.
- `docs/design-quality.md` - контракт и фактическая приёмка.

Для продакшена нужны реальные контакты, обработчик заявок и подтверждённые коммерческие условия. Формы демонстрации не обращаются к внешним API; контактные данные не сохраняются в localStorage. Избранное хранится только на устройстве.


### Сказочная подача

`#showroom?phase=fairytale` открывает семь полных серий по десять карточек. Старые версии доступны в соседних вкладках. PNG 1600 × 1200 скачивается из полноэкранной галереи. Серии: commercial, home, interior, window, rus, ice, pastel; суффикс маршрута `-fairytale`.
