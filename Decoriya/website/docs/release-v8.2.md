## Движение и производительность

Вход hero: навигация −12→0 px, 640 ms с задержкой 120 ms; подпись Олеси 10→0 px, 1000 ms с задержкой 700 ms; фон scale 1.025→1 и прозрачность, 1200 ms. Это одноразовый вход, не бесконечный цикл.
Три новогодние схемы сохранены как растровые атласы: свет влево/вниз, декор в центре, поверхности вправо/вверх. CSS transform/scale, 850 ms, задержки слоёв 0/70/140 ms. Hover для мыши, переключение нажатием, Enter/Space, Escape. На mobile меньший разнос. При prefers-reduced-motion движение отключается.
Галерея — нативная горизонтальная прокрутка, стрелки и увеличение. Нет WebGL, покадровых видео и новых библиотек. Фотографии ниже первого экрана остаются lazy.
Новый стол: WebP 960×320 — 61 630 байт; 1920×640 — 213 184 байта. Предыдущий стол — 215 954 байта. PNG-мастер не публикуется. Responsive srcset и один кэшируемый ресурс на два слоя. CSS/JS имеют cache-busting `8.2.0` во всех трёх страницах.
