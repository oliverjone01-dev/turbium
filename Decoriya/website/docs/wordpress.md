# WordPress: Декория v9

Готовый архив: `wordpress/dekoriya-atelier-v9.zip`.

1. На staging WordPress загрузите ZIP через «Внешний вид → Темы → Добавить → Загрузить» и активируйте.
2. Тема выводит главную автоматически. В «Настроить → Декория: главная» доступны три строки hero и ссылка обращения. По умолчанию контакт ведёт в анкету Олеси на Профи.ру.
3. Секции находятся в `template-parts/landing.html`. Это classic PHP-тема; полноценный редактор всех разделов в админке и CPT-каталог не входят в эту версию. Галерея/сценарии едины с основным фронтендом. Для правки исходной главной используются `tools/templates/` и `tools/build-home-v9.py`, затем повторная упаковка.
4. Не отключайте запрет индексации staging. Для рабочего домена проверьте индексируемость и настройки SEO-плагина.

WordPress ≥ 6.6 / PHP ≥ 8.0. Фактически запущено на WordPress 6.8 / PHP 8.3 в официальном Playground: главная, CSS/JS/маски изображений, раскрытие сцены, выбор кейса в сообщении и отдельная страница проекта. Это не проверка боевого MySQL/хостинга.

Тема использует `wp_head`, `wp_footer`, `wp_body_open`, `title-tag`, зависимости defer-скриптов и хеши файлов для обновления кеша. Пути к ассетам указывают на URI установленной темы; ссылки кейсов — на разрешённые `?dk_project=` маршруты. Неизвестные ID возвращают 404. Личных данных сервер не принимает: поля только формируют текст для копирования, реальный контакт — по ссылке Профи.ру.

## Пересборка

```sh
python3 tools/build-home-v9.py
python3 tools/package-wordpress.py
python3 tools/check-v9.py
node --check site-core.js
node --check v9-motion.js
```

Упаковщик копирует только используемые файлы и удаляет старый сгенерированный runtime из каталога темы. Не редактируйте этот каталог как независимый исходник. Новая главная не зависит от старых `app.js`, `motion-config.js` и 3D-атласов.

## Местная установка для проверки

```sh
npm exec --yes --package=@wp-playground/cli -- wp-playground-cli server --port=8797 --workers=1 --php=8.3 --wp=6.8 --blueprint="$PWD/tools/wp-blueprint.json" --mount="$PWD/wordpress/dekoriya-atelier:/wordpress/wp-content/themes/dekoriya-atelier"
```

Playground — временная установка с SQLite. Производственную установку, аналитику и приём заявок на сервере следует проверять на выбранном хостинге после подключения соответствующих сервисов.
