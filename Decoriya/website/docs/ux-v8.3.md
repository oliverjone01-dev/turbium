# Декория v8.3: короткий путь к обращению

17.11.2026. Источник приёмов: ZNANIYA_UI_UX_referensy_2026-09-23.md, разделы 3, 4, 8, 9, 12. Бордовый, ivory, фотографии и растровые сцены сохранены.

## Путь клиента
Основное действие: CTA страницы → контакт → «Написать Олесе» → существующая анкета Профи.ру. Форма не обязательна для этого перехода.
Дополнительный сценарий: два необязательных поля (задача, контакт) → скопировать сообщение → вставить в чат. Контекст услуги, палитры и работы добавляется автоматически. Нет обязательного квиза, загрузки файлов, календаря, длинного опросника и промежуточного подтверждения. Неизвестные параметры не подставляются в текст. При недоступном clipboard показывается текст для ручного копирования. Сообщение не объявляется отправленным.

## Карта приёмов из MD
| Приём | Решение |
|---|---|
| Короткая реакция состояния, без пружин | Переход содержимого 180 ms, стрелки кнопок 180 ms |
| Выбор отличается не только цветом | Индикатор выбранной вкладки/фильтра, aria-pressed |
| Magic/Spotlight Card, 6% | Мягкий отлив на кликабельном, только fine mouse, координаты через rAF |
| Отзыв на нажатие | Кнопка смещается на 1 px; клавиатурный фокус виден |
| Контекстная навигация | Мобильная кнопка связи появляется после hero, исчезает у контакта и в модальном окне |
| Прокрутка и safe-area | Тонкий индикатор прогресса, безопасный нижний отступ, блокировка страницы под dialog |
| Понятный результат | Текст об успешном копировании через aria-live; без ложной отправки |
| Reduced motion | CSS отключает движение, подсветку и прогресс; JS не запускает декоративные переходы |
| Стекло, beam, шум, WebGL, shimmer | Не добавлены: конкурируют с фото и не сокращают путь клиента |
| Rive/Anime/React-компоненты | Новые рантаймы не нужны для этих приёмов; используется существующий vanilla frontend |
| Command palette, графики, числовые ticker | Не соответствуют задаче лендинга услуг |

MD рассматривается как референс. Его примеры синей/чёрной палитры, шрифтов и тёмной темы не заменяют айдентику Декории. Обещание «быстрее 3 секунд» и рост конверсии не выдаются за измеренные результаты.

## Проверка
Chrome: 320, 390, 768, 1024, 1440; два видимых поля, ноль обязательных, горизонтального вылета нет. Пройдены пустое копирование, заполнение задачи и автоматическая передача зоны/повода, открытие просмотра фотографии, блокировка страницы и скрытие плавающей CTA в dialog. JS syntax, локальные ресурсы, canonical и sitemap проходят проверку. Финальная композиция формы просмотрена после исправления конфликтовавшего CSS grid.
Окончательная доставка сообщения выполняется в Профи.ру самим клиентом; backend сайта не подключён. Физические устройства, пользовательский A/B-тест и полевые метрики скорости не проверялись.
