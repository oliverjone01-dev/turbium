# ФЕНИКС: Декория v9.0.0

Дата: 17 ноября 2026. Авторская самопроверка, не независимый аудит.
Объект: каноническая главная, два кейса и собираемая из тех же файлов WordPress-тема. Главная содержит 14 секций; отдельного нового прототипа для посетителя нет.

## Что действительно проверено

- Chrome: desktop и мобильная компоновка. Отдельная размерная фикстура: 320, 390, 768, 1280, 1440, 1920 px, без горизонтального переполнения, один видимый H1, поля 16 px.
- Визуально просмотрены все секции. Для размерной фикстуры изображения загружались заранее; это проверка компоновки, а не скорости сети. Скриншоты находятся в рабочем арт-пакете `review/release-v9/`.
- Основные CTA: выбор бизнеса, две работы, три зоны, три масштаба, проект по ТЗ, процесс, условия, памятка и контакт. Выбранный пример и параметры попадают в короткое сообщение; сброс удаляет контекст.
- Все 12 карточек портфолио открыты; четыре фильтра дали 7/3/2/12 фотографий. Следующий/предыдущий кадр, стрелки клавиатуры, обсуждение, Escape, возврат фокуса.
- Четыре этапа процесса; ракурсы и детали; четыре FAQ и раскрытие сметы.
- Пять пунктов мобильного меню: закрывают dialog и переходят к нужному якорю. Нижняя кнопка контакта показывается после hero и исчезает у контакта/в dialog.
- Прямой контакт открыл реальную анкету Олеси на Профи.ру. Тестовые сообщения не отправлялись.
- WordPress Playground: главная v9, подключение CSS/JS, изображения и inline-маски; мобильная сцена; выбор MYATA, копирование с WP-ссылкой; отдельный кейс по разрешённому маршруту.
- Структурно: локальные ресурсы и якоря, JSON данных, отсутствие дублей ID, порядок двух скриптов, метаданные, равенство файлов темы, содержимое ZIP. CI дополнительно проверяет PHP.

## Граница допуска

Для публикации на GitHub Pages в проверенной Chrome-среде известных существенных дефектов не осталось. Это не утверждение о безошибочности.

Покрытие совместимости частичное: физических iPhone/Android и Safari/Firefox в этом проходе не было. Не измерены полевые Core Web Vitals, конверсия, производственный WordPress-хостинг/MySQL. Обращение остаётся прямым переходом и копированием; серверная отправка не подключалась и не имитируется. Полный CMS-редактор всех разделов — отдельная следующая возможность, не свойство этой темы.
