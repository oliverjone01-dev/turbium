# Декория v9: реализованное движение

Один runtime для GitHub Pages и WordPress: `site-core.js`, `v9-motion.js`, `motion.css`, `v9.css`. Тема копирует эти файлы без изменений; `tools/check-v9.py` проверяет равенство исходников и ZIP.

| Секция / событие | Реализованное поведение | Телефон / запасной режим |
|---|---|---|
| Hero: первый вход | Навигация 440 мс, строки 560 мс со сдвигом 65 мс, подпись 460 мс. Текст по умолчанию виден | Строки 360 мс. Reduced motion: сразу конечное состояние |
| Hero: мышь | Только фон: сглаживание, предел 12/8 px. Человек, руки и стол неподвижны. rAF прекращается вне hero и скрытой вкладки | До 1200 px, без hover и при reduced motion эффект отключён |
| Бизнес | Четыре вкладки: текст и контекст CTA меняются сразу, фото после загрузки. Устаревший ответ не заменяет текущий выбор | Нажатие; стрелки, Home/End; одна активная вкладка в Tab-порядке |
| Кейсы | Фотография открывает отдельную страницу, CTA сохраняет выбранный кейс в обращении | Та же логика, без hover-зависимости |
| Новогодние схемы | Растровый атлас из трёх планов, CSS transform 700 мс, задержки 0/60/120 мс. Свет влево-вниз, декор в центре, поверхности вправо-вверх. Hover показывает, клик фиксирует, повторный клик собирает | Нажатие раскрывает и собирает. Escape закрывает. Нет WebGL, видео, тяжёлого 3D или непрерывного проигрывания |
| Портфолио | Нативный горизонтальный rail. Мышь перетягивает после порога 8 px; случайный клик после drag подавляется 350 мс. Кнопки листают на 82% ширины | Нативный свайп/прокрутка. Фильтр обновляет счётчик. Фото открывается отдельно от перетягивания |
| Увеличение фото | Native dialog, резервированная высота фото, загрузка/ошибка, соседние кадры, оригинал, обсуждение. Escape и возврат фокуса | Закрытие всегда доступно; фон не прокручивается; controls переносятся в две колонки |
| Ракурсы и процесс | Кеширование кадров; токен запроса защищает от запоздалого ответа. Размер зарезервирован. Новый кадр появляется за 240–420 мс | 768 px WebP, выбор нажатием. При 503 остаются текст, действия и возможность выбрать соседний этап |
| Олеся | Мягкое движение портрета внутри дополнительной области, только при видимой секции | На телефоне статично, лицо и пропорции сохранены |
| Условия | Контурные иконки поднимаются при hover; секция появляется один раз | Статичная ясная композиция; действие не зависит от иконки |
| Смета / FAQ | Нативные details; короткое появление ответа и поворот знака | Enter/Space; без JS ответы доступны |
| Контакт | 120–200 мс отклик кнопок, видимый фокус, подготовка/успех/ручной запасной вариант копирования. Узкий фирменный паттерн проявляется один раз за 1800 мс | Два необязательных поля по 16 px. Прямая связь доступна без заполнения. Никакой имитации отправки заявки |
| Навигация | Компактная шапка после hero. На телефоне — меню и нижняя кнопка контакта; нижняя кнопка исчезает у контакта и в dialog | Safe area; reduced motion отключает переходы |

Изображения портфолио в rail: 12 отдельных WebP-превью, суммарно 1 188 052 байта вместо 4 228 338 байт полноразмерных файлов. Полный файл загружается при открытии. Новые сцены процесса — 768 px; мастера остаются в рабочем арт-пакете.

Не заявлено: полевые Core Web Vitals, физические iPhone/Android, Safari/Firefox, проверка производственного WordPress-хостинга. Проверка в Chrome и WordPress Playground не доказывает эти свойства.
