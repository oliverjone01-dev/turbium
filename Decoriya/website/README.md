## Текущие изменения v6.3

Сервисные схемы перерисованы в единой аксонометрической перспективе. Архитектура сохраняет вертикали и реальную глубину; её не наклоняет CSS-поворот плоского кадра. Поверхности уходят вниз-влево, декор и свет вверх-вправо. Тонкие пунктирные привязки проявляются после разлёта.

Девять чистых прозрачных PNG-мастеров и WebP 960 × 720 находятся в assets/axonometric-v63/. Отдельные слои не содержат фрагментов соседних предметов и направляющих. Суммарно девять новых WebP — 280 244 байта. Собранные постеры сохранены из v6.2.

Hover раскрывает, уход собирает; клик закрепляет. На телефоне тап раскрывает, повторный собирает. Клавиатура: фокус раскрывает, Escape собирает. Переход 1250 мс, только translate/opacity, без покадрового JavaScript. Ракурс заложен в заранее отрисованных растровых видах: это не непрерывный 3D-облёт и не модель WebGL. При reduced motion состояния переключаются без движения. До загрузки слоёв сохраняется исходный постер; ошибка допускает повторную загрузку.

Hero, лицо Олеси, стол и остальные разделы сохранены.

## Проверка и сборка

```sh
python3 -m http.server 8772
python3 tools/check.py
node --check app.js
node --check motion.js
node --check motion-config.js
python3 tools/package-wordpress.py
```

`qa.html`: восемь ширин, обычный текст и +25%. `wordpress/dekoriya-atelier-v63.zip` создаётся последней командой; готовый ZIP также собирает CI. Репозиторий хранит PHP-каркас и общий фронтенд, без повторных копий ассетов. Инструкции установки — `docs/wordpress.md`, результаты проверки — `docs/acceptance.md`.

## Файлы и поведение

| Файл | Назначение |
|---|---|
| `index.html` | Семантическая главная, статические карточки, нативные SVG |
| `media.json`, `media/` | Данные 20 кадров и страницы просмотра без JavaScript |
| `site.css`, `wow.css`, `spatial.css` | Токены, базовая композиция, пространственная графика и адаптив |
| `motion-config.js`, `motion-map.html` | Фактические параметры и 14 сценариев движения |
| `motion.js` | Вступление, слова, штрихи, CSS 3D, scroll/pointer |
| `app.js` | Галереи, меню, viewer, фильтры и помощник сообщения |
| `assets/exploded-v62/`, `assets/studio/`, `assets/spatial/` | Новые PNG-мастера/WebP, спокойная комната, стол, фото-сцены и SVG-иконки |
| `tools/` | Проверка, генерация карточек, упаковка темы |

Галереи сохраняют native scroll snap, drag мышью, свайп, стрелки, клавиатуру, фильтры, полноэкранный просмотр и миниатюры. Нет autoplay и перехвата вертикальной прокрутки. Не требуются GSAP, WebGL, jQuery, Elementor, внешний CDN или сборщик.
