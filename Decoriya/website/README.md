# Декория / Spatial v5

Главная для оформления бизнеса: Олеся за столом в просторном офисе, четыре раздельных векторных плана в каждом тизере услуг, две галереи с 20 изображениями. Айдентика: burgundy `#57212F`, ivory `#F6F0E5`, Golos Text.

[Открыть сайт](https://oliverjone01-dev.github.io/turbium/Decoriya/website/), [карта анимации](https://oliverjone01-dev.github.io/turbium/Decoriya/website/motion-map.html), [Figma desktop](https://www.figma.com/design/SsbOVLwLJnNFPwaeQ3bRqJ?node-id=93-3), [mobile](https://www.figma.com/design/SsbOVLwLJnNFPwaeQ3bRqJ?node-id=93-521), [состояния и motion-спецификация](https://www.figma.com/design/SsbOVLwLJnNFPwaeQ3bRqJ?node-id=99-1194).

## Изменения v5

1. Новые отдельные слои офиса и стола. Исходный одобренный прозрачный портрет не изменён: лицо использует прежний файл. Портрет, стол и накладка рук входят единым объектом. Курсор двигает только комнату, максимум 44/24 px и 1,4°. На ширине ≤1100 px фон статичен.
2. Имитация подписи удалена; осталось имя и роль.
3. Технические подписи о генерации убраны из пользовательского пути. Пять фотографий обозначены как портфолио, пятнадцать визуализаций — как «Идея оформления». Нереализованные идеи не объявляются клиентскими кейсами.
4. Три SVG-композиции разъезжаются на поверхность, архитектуру, декор и свет. Hover/focus, tap/click и Escape. На телефоне доступно без наведения. Компоненты Figma имеют состояния Assembled/Exploded.
5. Шапка без рамки, скруглённой панели и бокового пустого поля.
6. Заголовки и манифест появляются словами через маски; исходный текст доступен до JavaScript и в режиме reduced motion.
7. Три фирменные SVG-иконки процесса: прорисовка штрихов при появлении и анимация деталей при наведении.
8. Удалён огромный повтор логотипа; в подвале одна компактная версия. Служебные ссылки остаются в документации.

## Проверка и сборка

```sh
python3 -m http.server 8772
python3 tools/check.py
node --check app.js
node --check motion.js
node --check motion-config.js
python3 tools/package-wordpress.py
```

`qa.html`: восемь ширин, обычный текст и +25%. `wordpress/dekoriya-atelier-v5.zip` создаётся последней командой; готовый ZIP также собирает CI. Репозиторий хранит PHP-каркас и общий фронтенд, без повторных копий ассетов. Инструкции установки — `docs/wordpress.md`, результаты проверки — `docs/acceptance.md`.

## Файлы и поведение

| Файл | Назначение |
|---|---|
| `index.html` | Семантическая главная, статические карточки, нативные SVG |
| `media.json`, `media/` | Данные 20 кадров и страницы просмотра без JavaScript |
| `site.css`, `wow.css`, `spatial.css` | Токены, базовая композиция, пространственная графика и адаптив |
| `motion-config.js`, `motion-map.html` | Фактические параметры и 13 сценариев движения |
| `motion.js` | Вступление, слова, штрихи, CSS 3D, scroll/pointer |
| `app.js` | Галереи, меню, viewer, фильтры и помощник сообщения |
| `assets/spatial/` | Мастера комнаты/стола, webp и редактируемые SVG-планы/иконки |
| `tools/` | Проверка, генерация карточек, упаковка темы |

Галереи сохраняют native scroll snap, drag мышью, свайп, стрелки, клавиатуру, фильтры, полноэкранный просмотр и миниатюры. Нет autoplay и перехвата вертикальной прокрутки. Не требуются GSAP, WebGL, jQuery, Elementor, внешний CDN или сборщик.

В Figma v5 — отдельная страница `06 SPATIAL / v5`, редактируемые тексты, SVG-планы, инстансы существующей дизайн-системы, новые переиспользуемые тизеры и иконки. Native Figma демонстрирует состояния и прототипные переходы. Точная CSS 3D, pointer-параллакс, штрихи и появление слов исполняются на сайте. Ранее проверенная v4 сохранена отдельной страницей.

Факты о команде — из [анкеты Олеси](https://profi.ru/profile/SerdyukovaAI/), сверка 10.11.2026. Рейтинг 4,82 и 61 отзыв относятся ко всем услугам анкеты. Новые фон и стол созданы по предоставленному паспорту фотографии. PNG/WebP одобренного портрета побайтно сохранены от v4; это не утверждение о совпадении прежней генерации с исходным селфи. Графика самостоятельная, принципы движения изучены по alex-dein.ru.

Это публичный интерактивный прототип и устанавливаемая стартовая тема WordPress. Полный редактор разделов в CMS, CRM и многостраничное SEO/GEO-развитие остаются следующим этапом; сохранён noindex. Текущая кнопка обращения ведёт в анкету Олеси, помощник сообщения ничего не отправляет.
