## Текущие изменения v6.4

Для каждой из трёх схем построена постоянная 3D-геометрия и отрендерованы 48 настоящих ракурсов в Blender 4.5.9 LTS. Камера проходит 30° по горизонтали и поднимается на 12°. Это покадровое воспроизведение рендера, а не CSS-поворот цельной плоской картинки.

Раскрытие:1 — свет,2 — декор,3 — поверхности. Свет и декор движутся влево; основа немного вправо. Дизайнерские переносные фонарики со свечами заменили настенные светильники входа. Пунктирные связи тоже отрендерованы в 3D.

В assets/camera-v64/ находятся десктопные атласы 512×384 накадр, мобильные 384×288, статичные постеры 1024×768 и camera-manifest.json с реальными параметрами каждого кадра. Размер мобильной серии каждой схемы — 0,50–0,60 МБ. Атласы загружаются только после взаимодействия, статичные постеры работают до загрузки и при reduced motion.

Проигрыватель Canvas смешивает соседние ракурсы, работает только во время перехода 1800 мс и поддерживает обратный ход с текущей позиции. Hover открывает; клик закрепляет. Тап открывает, повторный собирает. Escape закрывает. При потере видимости или уходе со страницы анимация останавливается. На физическом телефоне FPS не измерялся; функциональное и временное поведение проверено в Chrome с шириной 360 px.

Исходный 3D-скрипт — tools/render-camera-v64.py. PNG-кадры и упакованный .blend сохранены в рабочем пакете landing-2026-11-11-v64/final-render. Материалы созданы встроенным image_gen; детали и сцены рендерятся из постоянной геометрии. Hero и лицо Олеси не менялись.

## Проверка и сборка

```sh
python3 -m http.server 8772
python3 tools/check.py
node --check app.js
node --check motion.js
node --check motion-config.js
python3 tools/package-wordpress.py
```

`qa.html`: восемь ширин, обычный текст и +25%. `wordpress/dekoriya-atelier-v64.zip` создаётся последней командой; готовый ZIP также собирает CI. Репозиторий хранит PHP-каркас и общий фронтенд, без повторных копий ассетов. Инструкции установки — `docs/wordpress.md`, результаты проверки — `docs/acceptance.md`.

## Файлы и поведение

| Файл | Назначение |
|---|---|
| `index.html` | Семантическая главная, статические карточки, нативные SVG |
| `media.json`, `media/` | Данные 20 кадров и страницы просмотра без JavaScript |
| `site.css`, `wow.css`, `spatial.css` | Токены, базовая композиция, пространственная графика и адаптив |
| `motion-config.js`, `motion-map.html` | Фактические параметры и 14 сценариев движения |
| `motion.js` | Вступление, слова, штрихи, CSS 3D, scroll/pointer |
| `app.js` | Галереи, меню, viewer, фильтры и помощник сообщения |
| `assets/camera-v64/`, `assets/studio/`, `assets/spatial/` | Новые PNG-мастера/WebP, спокойная комната, стол, фото-сцены и SVG-иконки |
| `tools/` | Проверка, генерация карточек, упаковка темы |

Галереи сохраняют native scroll snap, drag мышью, свайп, стрелки, клавиатуру, фильтры, полноэкранный просмотр и миниатюры. Нет autoplay и перехвата вертикальной прокрутки. Не требуются GSAP, WebGL, jQuery, Elementor, внешний CDN или сборщик.

В Figma v6.4 — девять контрольных поз Closed/Turning/Exploded (кадры 0/24/47), переиспользуемые компоненты и инстансы desktop/mobile. Точная последовательность 48 кадров и обратное воспроизведение реализованы в веб-прототипе. Контрольные позы Figma не заменяют проверку проигрывателя в браузере.

Факты о команде — из [анкеты Олеси](https://profi.ru/profile/SerdyukovaAI/), сверка 10.11.2026. Рейтинг 4,82 и 61 отзыв относятся ко всем услугам анкеты. Новые студийный фон, непрерывный стол и расширенный кадр материалов созданы по предоставленному паспорту фотографии. PNG/WebP одобренного портрета побайтно сохранены от v4/v5; исправленные нижние руки и рукава — отдельный файл; это не утверждение о совпадении прежней генерации с исходным селфи.
