# Декория / Studio v6.1

Главная для оформления бизнеса. Burgundy `#57212F`, ivory `#F6F0E5`, Golos Text. Публичная демонстрация фронтенда и устанавливаемая стартовая WordPress-тема.

[Сайт](https://oliverjone01-dev.github.io/turbium/Decoriya/website/), [карта движения](https://oliverjone01-dev.github.io/turbium/Decoriya/website/motion-map.html), [Figma desktop](https://www.figma.com/design/SsbOVLwLJnNFPwaeQ3bRqJ?node-id=109-1664), [mobile](https://www.figma.com/design/SsbOVLwLJnNFPwaeQ3bRqJ?node-id=109-2510), [состояния и motion](https://www.figma.com/design/SsbOVLwLJnNFPwaeQ3bRqJ?node-id=116-1119).

## Текущие изменения v6.1

1–2. Столешница проходит за оба края hero; отсутствуют боковые обрывы отдельно стоящего стола.
3. Исходное лицо и верх портрета сохранены. Кисти, манжеты и нижние рукава исправлены отдельным растровым слоем с мягкой верхней маской и контактной тенью. Исправленная столешница без вазы не пересекается с рукавом на 1440 px.
4. За Олесей — спокойная светлая студия. Чистая стена за текстом, рабочий стол и двое людей только в глубине справа. Нет гардеробных стоек и крупной цветочной колонны. Это созданный для дизайна фон, не документальная фотография офиса.
5. Имитация кнопки «Тянуть» заменена действующей кнопкой «Листать», которая остаётся справа у галереи. Drag мышью не запускает native drag ссылки; клик по фото открывает viewer. Стрелки, клавиатура и свайп сохранены.
6. Три растровые мини-сцены с реалистичными материалами. Hover/focus/tap: подъём 7 px, масштаб 1.035, наклон от мыши ±3°/±4°, однократный блик 1400 мс. Переход 850 мс; у каждой рубрики три собственных пояснения. Архитектура остаётся цельной.
7. Убраны повторные бейджи «Идея оформления». У всех 20 кадров свои названия и редакционные описания. Направления остаются отдельной подборкой, в данных сохранён тип concept, они не выдаются за завершённые кейсы.
8. Для материального кадра добавлен фон слева и запас по высоте. Параллакс до ±105 px, запас 120 px; на мобильных до ±36 px.
9. Рейтинг заменён подтверждёнными форматами работы: концепция с нуля и оформление по готовому ТЗ. Подробности команды основаны на предоставленной анкете Олеси.
10. В контактах мягкий блик проявляет авторский векторный контур. Цикл 11 с работает только в видимой секции; reduced motion оставляет статичный рисунок.

## Проверка и сборка

```sh
python3 -m http.server 8772
python3 tools/check.py
node --check app.js
node --check motion.js
node --check motion-config.js
python3 tools/package-wordpress.py
```

`qa.html`: восемь ширин, обычный текст и +25%. `wordpress/dekoriya-atelier-v61.zip` создаётся последней командой; готовый ZIP также собирает CI. Репозиторий хранит PHP-каркас и общий фронтенд, без повторных копий ассетов. Инструкции установки — `docs/wordpress.md`, результаты проверки — `docs/acceptance.md`.

## Файлы и поведение

| Файл | Назначение |
|---|---|
| `index.html` | Семантическая главная, статические карточки, нативные SVG |
| `media.json`, `media/` | Данные 20 кадров и страницы просмотра без JavaScript |
| `site.css`, `wow.css`, `spatial.css` | Токены, базовая композиция, пространственная графика и адаптив |
| `motion-config.js`, `motion-map.html` | Фактические параметры и 14 сценариев движения |
| `motion.js` | Вступление, слова, штрихи, CSS 3D, scroll/pointer |
| `app.js` | Галереи, меню, viewer, фильтры и помощник сообщения |
| `assets/studio/`, `assets/spatial/` | Новые PNG-мастера/WebP, спокойная комната, стол, фото-сцены и SVG-иконки |
| `tools/` | Проверка, генерация карточек, упаковка темы |

Галереи сохраняют native scroll snap, drag мышью, свайп, стрелки, клавиатуру, фильтры, полноэкранный просмотр и миниатюры. Нет autoplay и перехвата вертикальной прокрутки. Не требуются GSAP, WebGL, jQuery, Elementor, внешний CDN или сборщик.

В Figma v6.1 — страница `07 STUDIO / v6.1`, редактируемые тексты, растровые фото-сцены, инстансы существующей дизайн-системы, новые переиспользуемые тизеры и иконки. Native Figma демонстрирует состояния и прототипные переходы. Точный наклон растров, pointer-параллакс, штрихи, появление слов и световой паттерн исполняются на сайте. Ранее проверенная v4 сохранена отдельной страницей.

Факты о команде — из [анкеты Олеси](https://profi.ru/profile/SerdyukovaAI/), сверка 10.11.2026. Рейтинг 4,82 и 61 отзыв относятся ко всем услугам анкеты. Новые студийный фон, непрерывный стол и расширенный кадр материалов созданы по предоставленному паспорту фотографии. PNG/WebP одобренного портрета побайтно сохранены от v4/v5; исправленные нижние руки и рукава — отдельный файл; это не утверждение о совпадении прежней генерации с исходным селфи. Графика самостоятельная, принципы движения изучены по alex-dein.ru.

Это публичный интерактивный прототип и устанавливаемая стартовая тема WordPress. Полный редактор разделов в CMS, CRM и многостраничное SEO/GEO-развитие остаются следующим этапом; сохранён noindex. Текущая кнопка обращения ведёт в анкету Олеси, помощник сообщения ничего не отправляет.
