# Декория / Atelier v4

Новая главная для оформления бизнеса: многослойный hero с отдельным прозрачным портретом Олеси, две горизонтальные галереи, собственная архитектурная графика и реализованная анимация. Айдентика: burgundy `#57212F`, ivory `#F6F0E5`, Golos Text.

## Открыть и проверить

```sh
python3 -m http.server 8769
```

Откройте `http://127.0.0.1:8769/`. Сборщик и внешние JS-библиотеки для работы сайта не нужны. `motion-map.html` показывает живой hero и описание каждого сценария из фактической конфигурации. `design-system.html` содержит основы и состояния; `qa.html` измеряет восемь ширин с обычным и увеличенным на 25% текстом.

```sh
python3 tools/check.py
node --check app.js
node --check motion.js
node --check motion-config.js
python3 tools/package-wordpress.py
```

Последняя команда создаёт устанавливаемую тему `wordpress/dekoriya-atelier-v4.zip`. В Git хранится её PHP-каркас и общий фронтенд; копии изображений и готовый ZIP воспроизводятся командой, чтобы не дублировать пакет.

## Что изменилось

- Фон hero продолжается под плавающую шапку. Олеся — отдельный слой с альфа-каналом. После входа лицо статично; параллакс относится к фону.
- Вступление: шапка, строки из масок, фигура и линия подписи. Далее работают раскрытие SVG, текст по скроллу, параллакс материалов, прогресс этапов и чтения, небольшое смещение CTA для мыши.
- Пять исходных фотографий обработаны по отдельности. Viewer переключает исходник и ИИ-ретушь. Пятнадцать новых изображений помечены как ИИ-концепции для обсуждения, без вымышленных завершённых проектов.
- Галереи: native scroll snap, drag мышью, свайп, стрелки, клавиатура, фильтры, полноэкранный просмотр и миниатюры. Нет autoplay и перехвата вертикальной прокрутки.
- Мобильный hero перестраивается: предложение перед портретом, лицо целиком, фиксированное действие по контексту. `prefers-reduced-motion` отключает декоративное движение; контент видим без JavaScript.

## Карта проекта

| Файл | Назначение |
|---|---|
| `index.html` | Семантическая главная и статические карточки |
| `media.json` | 20 изображений, подписи, тип, категория и исходники |
| `tools/update-media.py` | Обновить карточки, встроенные данные и страницы без JS после изменения media.json |
| `site.css`, `wow.css` | Базовые токены, состояния, адаптив и новая композиция |
| `motion-config.js` | Единый источник таймингов и описаний 13 сценариев |
| `motion.js` | Вступление, viewport/scroll и pointer эффекты |
| `app.js` | Меню, галереи, viewer и помощник сообщения |
| `motion-map.html` | Живая карта анимации с replay |
| `media/` | Просмотр каждого изображения без JavaScript |
| `assets/` | Логотипы, шрифты, SVG, оптимизированные фотографии |
| `docs/wordpress.md` | Установка, границы CMS и развитие сайта |
| `docs/acceptance.md` | Проверенное поведение и ограничения проверки |

Не добавлены неподтверждённые цены, сроки, награды и показатели бизнеса. Визуальные и motion-принципы изучены на [alex-dein.ru](https://alex-dein.ru); конкретная композиция и графика созданы для Декории.

Фотография: генерация и ретушь выполнены по предоставленному паспорту качества; лицо сверялось с предоставленными и ранее одобренными изображениями. Генеративный портрет сохраняет узнаваемость, но не объявляется пиксельно идентичной копией исходного лица. Локальные PNG-мастера всех генераций сохранены в рабочей папке проекта; Git-пакет содержит веб-экспорты и PNG двух слоёв hero.

Это проверяемый фронтенд и устанавливаемая стартовая тема. Публичный запуск, интеграция CRM, полный редактор портфолио в CMS и многостраничное SEO-развитие — отдельный следующий этап; текущий прототип использует `noindex`.
