## Текущие изменения v6.2

Три сервисных тизера теперь разбираются на независимые прозрачные растровые планы: поверхности, декор и свет. Средняя витрина перерисована в общем правом ракурсе. PNG-мастера сохраняются; веб использует WebP 960 × 720 с альфой — 12 файлов суммарно 968 348 байт.

Hover мышью раскрывает сцену, уход собирает обратно; клик закрепляет. На телефоне тап раскрывает, повторный собирает. Клавиатура: фокус раскрывает, Escape собирает. Во время загрузки слоёв собранная сцена сохраняется; повтор загрузки доступен при ошибке.

Камера плавно поворачивается вправо и вверх: X 10°, Y −9°, scale .94→.81 за 1100 мс. Поверхности уходят назад, декор вперёд, свет выше и правее. Параметры XYZ, тайминги и камера заданы в `motion-config.js`; отрисовка — CSS perspective/transform, без покадрового JavaScript и видеоплеера. При обратной сборке планы остаются видны до возврата цельного кадра. Reduced motion показывает статичный разобранный вид.

Hero, лицо Олеси, стол и остальные секции сохранены из v6.1.

## Проверка и сборка

```sh
python3 -m http.server 8772
python3 tools/check.py
node --check app.js
node --check motion.js
node --check motion-config.js
python3 tools/package-wordpress.py
```

`qa.html`: восемь ширин, обычный текст и +25%. `wordpress/dekoriya-atelier-v62.zip` создаётся последней командой; готовый ZIP также собирает CI. Репозиторий хранит PHP-каркас и общий фронтенд, без повторных копий ассетов. Инструкции установки — `docs/wordpress.md`, результаты проверки — `docs/acceptance.md`.

## Файлы и поведение

| Файл | Назначение |
|---|---|
| `index.html` | Семантическая главная, статические карточки, нативные SVG |
| `media.json`, `media/` | Данные 20 кадров и страницы просмотра без JavaScript |
| `site.css`, `wow.css`, `spatial.css` | Токены, базовая композиция, пространственная графика и адаптив |
| `motion-config.js`, `motion-map.html` | Фактические параметры и 14 сценариев движения |
| `motion.js` | Вступление, слова, штрихи, CSS 3D, scroll/pointer |
| `app.js` | Галереи, меню, viewer, фильтры и помощник сообщения |
| `assets/exploded-v62/`, `assets/studio/`, `assets/spatial/` | Новые PNG-мастера/WebP, спокойная комната, стол, фото-сцены и SVG-иконки |
| `tools/` | Проверка, генерация карточек, упаковка темы |

Галереи сохраняют native scroll snap, drag мышью, свайп, стрелки, клавиатуру, фильтры, полноэкранный просмотр и миниатюры. Нет autoplay и перехвата вертикальной прокрутки. Не требуются GSAP, WebGL, jQuery, Elementor, внешний CDN или сборщик.

В Figma v6.2 — страница `07 STUDIO / v6.2`, редактируемые тексты, растровые фото-сцены, инстансы существующей дизайн-системы, новые переиспользуемые тизеры и иконки. Native Figma демонстрирует состояния и прототипные переходы. В Figma шесть состояний Closed/Exploded содержат реальные растровые слои; поворот показан приближённой 2D-проекцией. Точная непрерывная 3D-проекция, pointer-параллакс, штрихи, появление слов и световой паттерн исполняются на сайте. Ранее проверенная v4 сохранена отдельной страницей.
