# Приём заявок ДЕКОРИИ

На сайте две формы. Короткая передаёт имя и телефон и отмечается как «Перезвонить». Форма внизу страницы также передаёт описание и контекст выбранного оформления. Сайт подтверждает приём после ответа обработчика.

Статическая страница отправляет JSON методом POST на публичный HTTPS-адрес из переменной репозитория GitHub `DEKORIYA_LEAD_ENDPOINT`. Workflow Pages читает переменную при сборке. Публичный адрес не содержит токенов или паролей. Обработчик разрешает запросы со страницы и возвращает JSON `{"ok":true}` после фактической передачи заявки.

Если готового обработчика нет, `worker.mjs` можно подключить на хосте с доступом к боту. Укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в секретах хоста и задайте `LEAD_ORIGIN` равным origin сайта. Установите ограничение частоты публичных запросов к этому маршруту. После настройки проверьте обе формы с согласованными тестовыми заявками и подтвердите получение у команды.

Для локальной проверки укажите адрес тестового обработчика при вызове `python3 Decoriya/website/tools/build-home-v9.py`. Сборку с тестовым адресом не публикуйте.
