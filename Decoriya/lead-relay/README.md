# Приём заявок ДЕКОРИИ

Статическая страница отправляет JSON методом POST на публичный HTTPS-адрес. Включите адрес при сборке `DEKORIYA_LEAD_ENDPOINT=https://… python3 Decoriya/website/tools/build-home-v9.py`. Если пользовательский бот уже принимает HTTP-заявки, его обработчик должен разрешать исходный домен страницы и отвечать JSON `{"ok":true}` только после подтверждённой передачи. Публичная форма скрыта до настройки адреса. Кнопка Telegram открывает чат отдельно.

`worker.mjs` — готовый адаптер для среды Web Fetch. Хост должен хранить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в секрете. Они никогда не передаются в HTML, Git или клиентские логи. `LEAD_ORIGIN` определяет допустимый origin. Для публичной выкладки настройте на хостинге ограничение частоты POST к endpoint. После установки проверьте получение одной пробной заявки согласованным получателем.

Форма передаёт имя, контакт, пожелание, признак согласия и доступный контекст выбранного примера. Адаптер ждёт подтверждения `sendMessage` от Telegram. В случае ошибки клиент показывает состояние ошибки и оставляет поля заполненными.
