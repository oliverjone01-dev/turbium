# atlas/ - рабочая зона ветки `atlas-revmap`

Ветка под проект **Атлас / revmap**: здесь живут исходники лендингов, сайтов и
сопутствующих материалов, отсюда они уезжают в публикацию.

Git не допускает пробелов в именах веток, поэтому «Atlas Revmap» = `atlas-revmap`.

## Правила зоны

1. Внутри `atlas/` можно свободно двигать структуру проектов. Корневые папки
   репозитория (`site/`, `www/`, `content/`, `research/`) руками из этой ветки не трогаем,
   чтобы не ловить конфликты с `main`.
2. Правила TURBIUM (`CLAUDE.md`) действуют и здесь: источник или тег на каждую цифру,
   вымышленных кейсов нет, запретный словарь, дефис вместо длинного тире.
3. Публичный артефакт (лендинг, оффер, письмо) проходит adversarial-гейт
   (`phoenix-eval`) до публикации. Отчёт кладём в `atlas/<проект>/audit/`.

## Структура проекта

```
atlas/
  README.md              этот файл
  revmap/
    site/                то, что публикуется: index.html, стили, картинки
    content/             офферы, скрипты звонков, тексты до вёрстки
    outreach/            шаблоны касаний, база целей
    research/            аудиты карточек, цифры с источниками
    audit/               отчёты phoenix-eval
```

Новый проект в этой ветке - новая папка `atlas/<имя>/` по той же схеме.

## Публикация

Публикация на GitHub Pages идёт из `main` воркфлоу `.github/workflows/pages.yml`.
В этой ветке воркфлоу расширен: всё, что лежит в `atlas/<проект>/site/`,
раскладывается в `_site/atlas/<проект>/`.

Итоговые адреса после мержа в `main`:

| Источник | Адрес |
|---|---|
| `www/` | `/` |
| `site/turbium-locked.html` | `/platform/` |
| `strategy/strategy-locked.html` | `/strategy/` |
| `atlas/revmap/site/` | `/atlas/revmap/` |

Порядок работы: собираем и правим в `atlas-revmap`, гоняем локальный превью,
проходим гейт, затем PR в `main`. Мерж в `main` = публикация.

Локальный превью:

```bash
python3 -m http.server 8080 --directory atlas/revmap/site
```

Ветка `atlas-revmap` сама по себе ничего не деплоит: боевой Pages собирается
только из `main`, чтобы черновик лендинга не перетирал живой сайт.
